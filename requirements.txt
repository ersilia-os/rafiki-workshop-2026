# The app's runtime, and the only file Streamlit Community Cloud installs, with
# pip. The data-preparation scripts have their own, in scripts/.
#
# Note what is NOT here: rdkit, and any packages.txt.
#
# rdkit's wheel needs libXrender.so.1 at import time, and Cloud's Python 3.14
# image does not carry it, so `from rdkit.Chem import Draw` fails on import.
# packages.txt cannot supply it either: the image has a stale bullseye-security
# apt source, bullseye LTS ended 2026-08-31, and an expired Release file makes
# apt-get exit non-zero, which aborts the build before pip runs. Both were
# confirmed against the Cloud build log on 2026-09-08 - see git history.
#
# So the drawing moved to the browser: app/molecules.py renders molecules with
# RDKit.js compiled to WebAssembly. rdkit was used nowhere else in app/, so the
# server now needs it not at all. It remains a dependency of the scripts.
#
# Versions resolved on linux-64.
