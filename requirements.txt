# The app's runtime, and the only file Streamlit Community Cloud installs -
# with pip. The data-preparation scripts have their own, in scripts/.
#
# There is deliberately no packages.txt. Community Cloud's image carries a
# leftover Debian bullseye-security apt source, and bullseye LTS ended on
# 2026-08-31, so that repository's Release file is permanently expired: any
# packages.txt makes apt-get exit non-zero and the build aborts before pip runs.
#
# Confirmed 2026-09-08 by putting one back and reading the build log: apt-get
# hits an expired bullseye-security Release file, returns non-zero, and Cloud
# aborts the build before pip runs. packages.txt cannot work here at all.
#
# rdkit's wheel needs libXrender.so.1 at import time and Cloud's Python 3.14
# image does not have it, so `from rdkit.Chem import Draw` fails on import.
# rdkit.Chem itself is fine without X11 - it is only the Draw module. A fix for
# the drawing is in progress; until then the app cannot start.
#
